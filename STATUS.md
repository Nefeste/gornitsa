репозиториев, права по классам и автослияние, CI на PR, роли Управляющий, Ревьюер, Дежурный.

**Последние ADR:** [0017](adr/0017-repo-visibility.md), [0018](adr/0018-change-classes-automerge.md),
[0019](adr/0019-ci-on-pr.md).

  в «Сенях» — только для документов и тестов.

в настройках репозиториев; защита веток — только у открытых (у закрытых на бесплатном
тарифе её нет, Pro пока не берём — ADR 0017); удаление пре-релизов `build-N`; доска
GitHub Projects «Горница».
