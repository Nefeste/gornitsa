# Состояние устава

**Редакция:** первая — 27.09.2026; дополнена решениями владельца от 03.10.2026: видимость
репозиториев, права по классам и автослияние, CI на PR, роли Управляющий, Ревьюер, Дежурный;
от 10.10.2026: «Без давления» у ролевых игр с темпом (ADR 0010) и возврат игры, пропавшей по
вине игры, из ночной копии (ADR 0007).

**Последние ADR:** [0018](adr/0018-change-classes-automerge.md), [0019](adr/0019-ci-on-pr.md),
[0020](adr/0020-generators-pc.md) — генераторы графики в ПК-играх под отдельной маркой.

**Что сейчас:**

- PR в проекты по ADR 0017–0019 открыты: сборка APK только по тегу, без ручного запуска
  (в «Анамнезе» — без AAB); `CODEOWNERS` и `STATUS.md` на сайте и в «Сенях»; автослияние
  в «Сенях» — только для документов и тестов.
- `gornitsa-kit` создан (открытый), пока пустой.
- Зашифрованные копии баз на компьютере владельца в России (решение №15) — в
  [`docs/07-privacy.md`](docs/07-privacy.md); политика на сайте — Nefeste/gornitsagames#41.
- Реквизиты ИП — в [`docs/03-team.md`](docs/03-team.md#владелец) после регистрации.

**Предложено 27.10.2026:** [`docs/11-new-games.md`](docs/11-new-games.md) — путь новой игры
(замысел → прототип → вертикальный срез → путь к 1.0), разделы спецификации прототипа
(сквозной путь с бюджетом времени, ощущение числами, обёртка, бюджет кадра), графика и звук из
скриптов (Blender в фоне на ПК), решения агента, журнал проверок и два прохода по снимкам.

**Ждёт владельца:** слияние PR в проектах; метка `ревью: ок` и «Allow auto-merge»
в настройках репозиториев; защита веток — только у открытых (у закрытых на бесплатном
тарифе её нет, Pro пока не берём — ADR 0017); удаление пре-релизов `build-N`; доска
GitHub Projects «Горница».
