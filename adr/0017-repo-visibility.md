# 0017. Видимость репозиториев: устав и сайт открыты, игры, «Сени» и «Управа» закрыты

**Решили** (решение владельца 03.10.2026).

- **Открыты:** устав `Nefeste/gornitsa` и сайт `Nefeste/gornitsagames`.
- **Закрыты:** игры `votchina`, `nardy`, `skazy`, `uzory`, `anamnez`, шлюз `seni`
  и `uprava`.
- Денежное и внутреннее студии — очередь решений владельца, расчёты, планы, аудиты,
  межпроектные факты — живёт в закрытом `Nefeste/uprava`, а не в уставе и не в проектах.
- Агенты получают доступ к закрытым репозиториям через приложение GitHub «Claude», которому
  владелец разрешает нужные репозитории. Пароли и личные токены владельца агенту для этого
  не нужны и не выдаются ([`../docs/03-team.md`](../docs/03-team.md)).
- Открытый репозиторий виден всем вместе с историей: в нём нет паролей, ключей, денежных
  расчётов, договоров и личных данных. Новый репозиторий студии по умолчанию закрыт;
  открыть его — решение владельца, записанное здесь новым ADR.

**Почему.**

- В уставе и сайте нет секретов: устав — правила и обещания, которые и так публичны
  (ADR [0001](0001-charter-repo.md)), сайт — то, что и так видно на gornitsa.games.
- Ссылки на устав в `AGENTS.md` всех проектов (`raw.githubusercontent.com/...`) работают
  без доступа, из любой среды агента. Когда устав был закрыт, агенты проектов его не видели.
- Автообновление сайта забирает `main` по HTTPS без ключа, а страницы игр читает по
  расписанию (ADR [0015](0015-site-from-store.md)); закрытый сайт это ломал.
- Минуты GitHub Actions для открытых репозиториев бесплатны; 2000 бесплатных минут в месяц
  остаются закрытым репозиториям (ADR [0019](0019-ci-on-pr.md)).
- В играх — код до выпуска, контент на проверке, материалы магазина и серверные настройки;
  в «Сенях» — устройство шлюза с ключами каналов; в `uprava` — деньги и планы. Их закрываем.

**Платим.**

- Каждый новый закрытый репозиторий владелец сам добавляет в приложение «Claude»; агент
  в среде, где приложения нет, закрытых репозиториев не видит.
- Сайт читает закрытые игры токеном только на чтение (`GAMES_READ_TOKEN`, ADR 0015);
  каждую закрытую игру нужно добавить и в список сайта, и в сам токен.
- Закрытые репозитории делят 2000 бесплатных минут Actions в месяц.
- Межпроектный факт, который не секрет, но и не правило (дата регистрации, номер вопроса),
  живёт в `uprava`; агенту проекта, чтобы его прочитать, нужен доступ и туда.

**Когда пересмотреть.** Перед открытием кода какой-либо игры, перед выходом игры с
открытым исходным кодом, или если минут Actions для закрытых репозиториев перестанет
хватать даже без сборок на PR.
