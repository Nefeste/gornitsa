# 0012. Контент — только из названных источников; генераторов изображений нет; «проверено» ставит человек

**Решили.**

- Любой текст, правило, сказка, медицинский факт, картинка, звук или шрифт берётся из
  названного источника с правовым основанием: общественное достояние, открытая лицензия,
  своё (код, снимки владельца, синтез), договор.
- Никогда: по памяти; из генераторов изображений; из чужих игр, мультфильмов и франшиз;
  торговые названия без договора.
- Запись контента несёт источник, основание и заметки об отступлениях; сборка не пропускает
  запись без них.
- Агент пишет запись как `review: draft`. `review: checked` ставит только человек; в выпуск
  идёт только проверенное.

**Откуда.** ADR 0008, 0012, 0013 «Анамнеза»; ADR 0015, 0016 «Сказов»; ADR 0006 «Узоров»;
правила «Сказов» для ассистента (`AGENTS.md`).

**Почему.**

- Память модели смешивает сказку с мультфильмом, болезнь с сериалом, свод правил с
  «домашним» вариантом; ошибка в медицине или в праве стоит дороже любой скорости.
- Картинки из генераторов — правовой туман (обучающие данные, сходство с чужими работами)
  и узнаваемый «нейросетевой» вид, который противоречит обещанию ремесла.
- Правообладатели франшиз по русским сказкам активно судятся (около сотни исков одной
  группы с начала 2026 года, см. `docs/11-money.md` «Сказов»).

**Платим.** Контент делается медленнее; часть материала (картины из российских музеев,
спорные снимки) недоступна без договора; вид игр ограничен тем, что умеет код.
