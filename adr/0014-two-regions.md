# 0014. Данные игроков из России — только в России; зарубежным игрокам — свои сборки и сервер в США; моделям ИИ — только обезличенный текст

**Решили.**

- Персональные данные игроков и переписка из России хранятся и обрабатываются только на
  машинах студии в России (серверы игр — ADR [0005](0005-offline-first-own-server.md),
  шлюз «Сени» — ADR [0013](0013-seni-gateway.md)). Трансграничной передачи персональных
  данных студия не делает.
- Моделям ИИ (Claude и другим, где бы они ни работали) и машинам за границей уходит только
  обезличенный текст: без адресов, телефонов, имён, ников, тегов профилей и ссылок на
  профили. Обезличивает шлюз «Сени» до передачи.
- Для игроков за пределами России, когда появится первая такая сборка, у студии будет своя
  машина в США. Такая сборка выходит в другом магазине, а не в RuStore; Россия исключена из
  стран её распространения; она говорит только с сервером в США. Сборка для RuStore говорит
  только с сервером в России. Регион определяет сборка, а не IP-адрес игрока.
- Машина в США заказывается вместе с первой зарубежной сборкой — решением владельца.
  «Мозгам» она не нужна: Claude работает в облаке Anthropic по подписке.

**Почему.** 152-ФЗ требует хранить данные россиян в России, а передача за границу — отдельная
процедура с уведомлением Роскомнадзора; владелец решил её не делать. Деление по сборке, а не
по IP, проверяется в коде: сборка RuStore просто не знает адреса сервера в США. Обезличенный
текст позволяет пользоваться сильными моделями, где бы они ни работали, не вынося из России
то, по чему можно узнать человека.

**Платим.** Когда появится зарубежная аудитория — две инфраструктуры вместо одной, а
профили между регионами не переносятся. Обезличивание автоматическое и несовершенное: имя
в тексте письма правило может пропустить, поэтому агент, заметивший личные данные, помечает
обращение, и правило дорабатывается. Это инженерное решение, а не юридическая консультация.
