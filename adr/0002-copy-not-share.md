# 0002. Каждая игра — свой репозиторий; общий код переносится копированием с пометкой источника

**Решили.** Каждая игра живёт в отдельном репозитории `Nefeste/<игра>`. Общий код
(диалог вместо `Alert`, механика текстов, журнал сбоев и «Сообщить об ошибке», сеть с ключом
устройства, перенос по коду, плагин подписи, сборка APK в CI, загрузка в RuStore, скелет
Expo Router, сборка контента, сервер Bun + SQLite, RuStore Pay) **копируется**, а не
подключается общим пакетом. Скопированный файл начинается строкой-источником:

```ts
// из votchina: src/ui/dialog.tsx @ 9f587e7
```

Общий пакет студии — отдельное решение студии, а не одной игры.

**Откуда.** Собрано из ADR 0001 «Длинных нард», «Сказов» и «Узоров» и ADR 0001 «Анамнеза»
(новый репозиторий вместо старого прототипа).

**Почему.**

- Игры в разных стадиях: «Вотчина» в магазине, остальные в разработке. Общий пакет —
  правка всех работающих репозиториев сразу и риск для вышедшей игры.
- Копия с пометкой источника — лучшее сырьё для будущего пакета: видно, что откуда взято
  и насколько разошлось.
- Копирование не задерживает новую игру: нужное появляется в день начала работы.

**Платим.** Исправление в скопированном коде переносится руками во все копии; пять игр —
пять копий диалога и сети. Чтобы не потерять: пометка источника; исправление в одном
репозитории — задача в остальных (поиск по `// из <репозиторий>:`).

**Когда пересмотреть.** «Правило трёх» уже сработало (пять игр). После этапа 1 «Сказов»
владелец решает, выносить ли в общий пакет ключ устройства и сеть, диалог, механику текстов,
журнал сбоев и отчёт, плагин подписи и workflow сборки (вопрос В12 в дорожной карте
«Сказов»). Решение записывается новым ADR здесь.

**Пересмотр решён** (решение владельца 03.10.2026). Общий набор студии `gornitsa-kit`
будет; он начинается с переиспользуемых workflow (`workflow_call`): подпись, проверки,
загрузка в RuStore. Код игр пока по-прежнему копируется с пометкой источника; что и когда
переходит из копий в набор — отдельными ADR здесь.
