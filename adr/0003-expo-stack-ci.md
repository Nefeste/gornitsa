# 0003. Expo / React Native / TypeScript; нативные папки генерируются; APK собирает CI без EAS и только после слияния (частично заменено 0019)

**Решили.**

- Все игры — Expo / React Native / TypeScript; рисование — Skia (сцены, карты, канва)
  или SVG (карточки «Вотчины»). Версия Expo SDK по возможности одна во всех играх.
- `ios/` и `android/` генерируются (Continuous Native Generation) и не правятся руками;
  нативное поведение — `app.json` и плагины конфигурации.
- APK собирает GitHub Actions (prebuild + Gradle) без аккаунта EAS, подписывает постоянным
  ключом из секретов репозитория (ADR [0006](0006-permanent-app-id-and-key.md)) и
  публикует в GitHub Releases.
- *(Заменено ADR [0019](0019-ci-on-pr.md): на PR — быстрые проверки, APK и AAB — на тег или
  выпуск.)* Сборка запускается **только после слияния в `main`** и вручную; на рабочих ветках и PR
  CI не запускается (решение владельца 27.09.2026). Проверки перед push агент прогоняет сам.
- Веб-сборка — стенд для автоматических проверок (Playwright), а не продукт; исключение —
  «Вотчина», у которой веб-версия — часть продукта (её ADR 0016).

**Откуда.** ADR 0002 «Анамнеза», «Сказов», «Узоров»; ADR 0015 «Анамнеза»; ADR 0013 «Вотчины»;
`05-process.md` всех игр.

**Почему.**

- Один стек — один набор знаний, общий код копируется без переписывания, агент переходит
  между играми без переучивания.
- Своя сборка в CI не зависит от чужого аккаунта и очереди EAS, а подпись постоянным
  ключом проверяется на готовом файле.
- Минуты GitHub Actions общие на все закрытые репозитории владельца (бесплатно — 2000 в месяц),
  а сборка APK — 15–30 минут; сборка на каждую ветку и ещё раз на `main` тратила вдвое больше.

**Платим.**

- Ошибка, которую поймал бы CI на PR, обнаруживается только после слияния, если агент не
  прогнал проверки сам. Поэтому локальные проверки перед push обязательны.
- Expo меняется с каждым SDK: документацию читаем по версии, а не по памяти.
- До 27.09.2026 «Длинные нарды» запускали проверки на ветках `claude/**`, а «Анамнез» — на
  `pull_request`; обе игры приведены к правилу (PR nardy #17 и anamnez #18).
