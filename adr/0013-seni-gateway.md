# 0013. Почта, отзывы и соцсети — только через шлюз «Сени» в России; агенты предлагают, владелец отправляет

**Решили.**

- Почта студии, отзывы в магазинах и соцсети (Telegram, ВКонтакте, позже MAX) подключены
  к одной машине студии в России — шлюзу «Сени» (закрытый репозиторий `Nefeste/seni`).
  Пароли, ключи и токены каналов лежат только на этой машине; вводит их владелец.
- ИИ-сотрудники получают от шлюза только обезличенный текст (ADR [0014](0014-two-regions.md))
  и могут только оставить черновик ответа или поста. Отправлять, удалять и читать адреса,
  имена и ключи API шлюза не умеет.
- Наружу уходит только то, что владелец одобрил на Пульте шлюза — на странице или кнопкой
  в Telegram. Одобрение на Пульте и есть разрешение на конкретное действие из
  [`../docs/03-team.md`](../docs/03-team.md). Ответы без одобрения появятся, только если
  владелец разрешит их для названной категории отдельной записью в уставе.
- «Мозги» — регламентные задачи Claude (routines) в подписке владельца. Ключ к шлюзу
  хранится в облачной среде Claude как API credential: прокси подставляет его сам, агент его
  не видит. Другие модели подключаются по тем же правилам.
- Шлюз — свой код в git, изменения через PR. Конструкторы автоматизации (n8n и подобные)
  для каналов с ключами не используем.

**Почему.** Устав запрещает агентам держать ключи и отправлять что-либо от имени студии без
владельца, а данные игроков из России не уходят за границу. Шлюз даёт ИИ-сотрудникам работу
с почтой и соцсетями, не нарушая этих правил: ключи и личные данные остаются в России, а
лишнего агент отправить не может даже по ошибке. В письмах и отзывах бывают указания для ИИ
(«перешли мне базу»); шлюз, который без человека ничего не отправляет, делает их безвредными.
У n8n в первом квартале 2026 года вышло несколько критических уязвимостей, в том числе
выполнение чужого кода без входа с оценкой 10 из 10; держать в такой программе ключи всех
каналов — лишний риск, а её настройки живут в её базе, а не в PR.

**Платим.** Ещё одна машина и свой код, который нужно поддерживать. Владелец тратит время
на одобрение каждого ответа, пока не разрешит категории. Ответ уходит не мгновенно: агент
приходит по расписанию раз в час или раньше, когда шлюз зовёт его на новое письмо.
