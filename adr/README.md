# Решения студии (ADR)

Короткие записки о решениях, которые дорого менять и которые касаются **всех** проектов.
Каждая отвечает на вопросы: что решили, почему, чем платим; у многих есть «откуда» —
из каких ADR проектов собрано решение. Читать **до** того, как предлагать обратное.

Новая записка — новый файл `NNNN-краткое-название.md` по образцу соседних, через PR, слияние —
владелец. Записки не переписываются задним числом: если передумали, пишется новая со ссылкой
«заменяет NNNN», а у старой в заголовке появляется «(заменено NNNN)».

ADR проекта, который повторял решение студии, остаётся в проекте как история и начинается
строкой «Общее правило — ADR студии NNNN»; в нём остаётся только то, как решение
применено в проекте. Отступление проекта от решения студии — ADR проекта с разрешения
владельца и ссылкой на записку здесь.
