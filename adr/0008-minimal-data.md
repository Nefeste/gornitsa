# 0008. Данные — минимум: своя статистика без идентификаторов, без SDK аналитики; политика одна на сайте

**Решили.**

- В играх нет SDK аналитики и трекеров. Чтобы понимать, остаются ли игроки, каждая игра
  раз в сутки отправляет на свой сервер анонимные счётчики (версия, число партий, есть ли
  покупка) без ника, профиля и идентификаторов устройства; «Узоры» считают даже не
  установки, а запросы каталога.
- Сервер хранит только то, без чего не работает онлайн, со сроками хранения; журналы
  запросов — 3 дня, копии базы — 7 дней.
- Рекламный SDK — только в игре, чья модель денег — реклама (сейчас «Длинные нарды»),
  с согласием по закону.
- Политика конфиденциальности — одна, на сайте, с разделом на каждую игру
  ([`../docs/07-privacy.md`](../docs/07-privacy.md)).

**Откуда.** ADR 0015 «Нард», 0020 «Сказов», 0012 «Узоров»; «Чего сознательно нет»
в `01-product.md` «Вотчины» и «Анамнеза»; README сайта (единая политика).

**Почему.** Обещание «мы не собираем лишнего» проверяемо, только если лишнего нет в коде.
SDK аналитики тянут идентификаторы, зарубежные серверы и разделы в политике, которые
нельзя честно объяснить бабушке.

**Платим.** Мы знаем об игроках меньше, чем конкуренты: нет воронок, когорт и тепловых
карт. Решения принимаем по счётчикам, отзывам и письмам.
