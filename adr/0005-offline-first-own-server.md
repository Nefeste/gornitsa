# 0005. Без сети по умолчанию; сервер — своя машина студии в России; с 1.0 сервер понимает предыдущую версию

**Решили.**

- Всё, что можно сделать без сервера, работает без интернета: игра с ботом, вдвоём на одном
  телефоне, одиночная кампания. Сервер нужен только тому, что без него невозможно: онлайн
  с людьми, застава, облачная копия, перенос профиля, пакеты картинок. У «Анамнеза» нет
  даже разрешения INTERNET (его ADR 0006).
- Серверы игр работают на своей машине студии в России — сейчас это VPS сайта gornitsa.games
  в Рег.облаке (Москва): Bun или Node, SQLite, nginx, автообновление из ветки `vps`
  репозитория игры, ежедневная копия базы. Настройка машины — `deploy/<игра>/` в
  `Nefeste/gornitsagames`.
- С первого выхода в магазин (1.0; у «Вотчины» — 2.0) сервер понимает предыдущую
  выпущенную версию приложения; несовместимой отвечает понятным «обновите игру» (`426`).

**Откуда.** ADR 0006 «Анамнеза», 0009 «Сказов», 0007 «Узоров»; ADR 0005, 0018 «Нард»,
0012 «Сказов», 0019 «Вотчины»; ADR 0015 «Вотчины», 0016 «Нард», 0021 «Сказов».

**Почему.**

- Жалоба номер один на игры в RuStore — «не работает без интернета». Наши игроки часто
  в дороге и с нестабильной сетью.
- 152-ФЗ требует хранить персональные данные россиян в России; своя машина — ещё и
  предсказуемые деньги и независимость от зарубежных облаков.
- Незнакомого человека нельзя попросить обновиться сегодня же; поэтому совместимость
  с предыдущей версией — обещание.

**Платим.**

- Одна машина — одна точка отказа; есть ежедневные копии, но нет горячего резерва.
- Администрирование — наше: обновления системы, сертификаты, место на диске, деньги на
  балансе Рег.облака.
- Переход «Вотчины» с Cloudflare закончен решением владельца (29.09.2026): старый адрес
  отключён, копия базы там удалена. Версии старше 2.10.2 остались без онлайна; игра без
  сети у них работает.

**Когда пересмотреть.** Когда нагрузка одной игры перестанет помещаться на машину
сайта — отдельная машина для этой игры, тоже в России.
