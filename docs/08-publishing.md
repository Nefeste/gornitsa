# Выпуск и магазины

Игры студии выходят сначала в RuStore. Другие магазины (Google Play и прочие) — только
решением владельца для конкретной игры; что они требуют сверх RuStore, записано в
документах той игры.

## Кто что делает

- **Агенты** готовят всё: сборку, тексты карточки, снимки, анкеты, раздел политики, страницу
  на сайте, черновик новой версии в консоли RuStore (через workflow `rustore.yml`).
- **Владелец** проверяет сборку на телефоне и **сам** отправляет версию на модерацию
  и публикует её. Аккаунт разработчика RuStore — владельца; доступы к нему агентам не
  передаются.

## Постоянное

- Имя разработчика в магазине — «Горница»; сайт — https://gornitsa.games; почта поддержки —
  support@gornitsa.games (в workflow — переменная `CONTACT_EMAIL`).
- Идентификатор приложения — `games.gornitsa.<игра>`, ключ подписи — постоянный, с первой
  сборки (ADR студии [0006](../adr/0006-permanent-app-id-and-key.md)).
- Ссылки, которые просит магазин, ведут на сайт студии: политика —
  `https://gornitsa.games/privacy`, удаление данных — `https://gornitsa.games/<игра>/delete`,
  поддержка — `https://gornitsa.games/support`.

## Материалы игры

Лежат в `store/` репозитория игры и собираются кодом, руками не правятся:

| Файл | Что |
|---|---|
| `store/listing.ru.md` (и `.en.md`) | название, краткое и полное описание, ключевые слова, «Что нового», категория; длины проверяет тест |
| `store/faq.ru.md` | частые вопросы — для сайта и ответов на отзывы |
| `store/forms.md` | ответы анкет RuStore: категория, возраст с обоснованием, разрешения, какие данные собираются |
| `store/preorder.md` | тексты предзаказа, если он есть |
| `store/site/page.ru.md` (и `.en.md`) | страница игры на gornitsa.games и карточка на главной — формат ниже, в разделе [«Сайт»](#сайт) |
| `store/site/press*.md` | коротко для прессы и блогеров ([`06-content.md`](06-content.md)); сайт их не читает — его страница «Для прессы» берёт жанр, статус, строку под названием, паспорт, баннер и значок из `page.*.md` |
| иконка 512×512 без прозрачности, снимки экрана, графика | собираются скриптами `tools/store/` из веб-сборки или кода; ими же пользуется сайт |

Описание в карточке пересказывает обещания студии ([`02-values.md`](02-values.md)) словами
игры и голосом студии ([`09-voice.md`](09-voice.md)). Чего в описании не бывает: превосходных
степеней без доказательства («лучшая»), обещаний, которых игра не выполняет, чужих
торговых знаков, слов «бесплатно», если в игре есть покупки без оговорки, что именно платно.

## Возрастная категория

Каждая игра проходит возрастную маркировку по 436-ФЗ в анкете RuStore; обоснование —
в `store/forms.md` игры. Категория выбирается по самому взрослому содержимому игры
(медицина, сражения, реклама), а не по желаемой аудитории.

## Версия в магазине

1. Выпуск по чек-листу ([`04-process.md`](04-process.md#выпуск) и `05-process.md` игры).
2. «Что нового» — тот же текст, что раздел версии в `README.md`, короче.
3. Workflow `rustore.yml` кладёт APK из GitHub Releases в черновик новой версии RuStore.
4. Владелец публикует. После публикации — строка в дорожной карте и новость на сайте,
   если версия заметная ([`10-channels.md`](10-channels.md#о-чём-пишем)).

## Отзывы и поддержка

- Отзывы читаются регулярно; повторяющаяся жалоба — задача в дорожной карте игры.
- Ответ на отзыв готовит роль «PR и сообщество» или «Поддержка» как черновик в шлюзе
  «Сени»; публикует его владелец кнопкой на Пульте ([ADR 0013](../adr/0013-seni-gateway.md)).
- Отвечаем по существу, без шаблонов и без просьб «поставьте пять звёзд».
  Не спорим, не обещаем сроков, которых не знаем.
- Письма в поддержку — на support@; ответ по существу, как обещано ([`02-values.md`](02-values.md)).

## Сайт

К первому закрытому тесту у игры есть страница на gornitsa.games (русская и английская),
раздел в политике конфиденциальности и, если есть профиль на сервере, страница удаления.

Страница игры и её карточка на главной собираются из `store/site/` игры, оформление — шаблон
сайта по брендбуку (ADR студии [0015](../adr/0015-site-from-store.md)). Раздел политики,
страницы удаления, новости, главная и порядок игр на ней правятся в репозитории сайта
`Nefeste/gornitsagames`.

### Когда обновлять

PR игры, который меняет видимое игроку — версию для теста или магазина, возможности,
снимки, цену, статус, — в том же PR правит `store/site/`. Больше ничего делать не нужно:
сайт раз в сутки ночью забирает `store/site/` с `main` каждой игры и открывает или обновляет
PR «Сайт: обновления игр», а сливает его владелец. Не дожидаясь ночи — кнопка «Run workflow»
у workflow «Страницы игр» в Actions сайта.

### Формат `store/site/`

`page.ru.md` — обязательно, `page.en.md` — когда у игры есть английская страница. Другие
файлы папки (`press*.md`, заметки) сайт не читает.

В начале файла — поля YAML между строками `---`, дальше — текст страницы в Markdown.
Строку с двоеточием и пробелом внутри или с кавычкой в начале берите в двойные кавычки.
Пути к картинкам — от папки `store/`; годятся PNG и WebP, размеры для сайта сайт делает сам.

```yaml
---
name: Узоры                          # название игры
title: Узоры — вышивка крестиком по номерам   # заголовок вкладки и ссылки в соцсетях, до 60 знаков
description: Раскраска по номерам в виде вышивки крестиком…   # для поиска и соцсетей, до 220 знаков
kind: Раскраска по номерам           # жанр: над названием и в карточке на главной, до 40 знаков
status: dev                          # dev — «В разработке», test — «Закрытый тест», live — «В RuStore»
lead: "Вышивка крестиком по номерам: выбираете нить и вышиваете."   # под названием, до 160 знаков
links:                               # кнопки под названием, первая — главная; можно не писать
  - text: Предзаказ в RuStore
    url: https://www.rustore.ru/catalog/app/games.gornitsa.uzory
icon: graphics/icon-512.png          # квадрат от 192 × 192
feature: graphics/feature-ru.png     # 1024 × 500: карточка на главной и ссылки в соцсетях
og: graphics/cover-1920x1080.png     # по желанию: картинка для ссылок, обрезается до 1200 × 630;
                                     # нет — сайт делает её из feature
cover: graphics/cover-site.png       # по желанию: обложка над названием, 3 : 1 от 1920 × 640, без надписей
shots:                               # 3–8 снимков одной формы: 9 : 16 от 540 × 960 или 16 : 9 от 960 × 540
  - file: screenshots/ru/01-stitch.png
    caption: Вышивание               # подпись под снимком, до 30 знаков
    alt: Льняная канва, крестики и номера нитей в клетках   # что на снимке — для незрячих, до 160 знаков
card:                                # карточка на главной
  text: "Вышивка крестиком по номерам: орнаменты, картины и Россия в цвете."   # до 240 знаков
  points:                            # 2–4 пункта, до 80 знаков
    - Работает без интернета
    - Без рекламы и без регистрации
  links:                             # по желанию: ссылки под карточкой после «Об игре»
    - text: RuStore
      url: https://www.rustore.ru/catalog/app/games.gornitsa.uzory
note: Игра. Не является медицинским изделием.   # по желанию: мелкая строка внизу страницы
facts:                               # по желанию: паспорт игры под кнопками, от 2 строк, до 40 знаков
  platform: Android                  # платформа
  price: бесплатно, без рекламы      # цена
  age: 0+                            # возраст — как в карточке RuStore
  players: один                      # игроки
  internet: не нужен                 # интернет
  languages: русский                 # языки игры
---
```

Текст страницы: абзацы, заголовки `##` (разделы) и `###` (вопросы в разделе «Вопросы»),
списки `-`, **жирный**, *курсив* и ссылки `[текст](https://…)`. Без HTML, картинок и таблиц.
Почта пишется как есть — support@gornitsa.games. Ссылки на политику конфиденциальности,
страницу удаления и страницу на другом языке сайт ставит внизу сам.

Паспорт (`facts`) — только то, что можно проверить по игре и её карточке RuStore (`store/forms.md`):
без сроков и обещаний. Строки идут в порядке примера, какие есть; возраст и платформу сайт
передаёт и поисковикам (разметка schema.org). Обложка (`cover`) — по правилу брендбука
([«Как игры носят бренд студии»](../brand/README.md#как-игры-носят-бренд-студии)): картина мира
игры без надписей, главное — в средней части 2 : 1.

Английский файл — те же поля по-английски; картинки в нём можно указать свои (снимки
английской сборки, `feature-en.png`) или те же, что в русском.

Тест `store` игры проверяет папку так же, как сайт: поля на месте и не длиннее нормы, файлы
картинок есть и нужной формы, у каждого снимка есть `alt`, в тексте нет HTML, ссылки —
только `https://` и `mailto:`. Папку, которая не прошла проверку, сайт пропускает и пишет
причину в PR. Проверить папку проверкой самого сайта: `python3 tools/games.py --check <папка игры>`
в репозитории сайта.
