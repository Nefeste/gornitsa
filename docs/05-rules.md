# Твёрдые правила для всех игр

Эти правила действуют в каждой игре студии. Каждое — одной строкой; почему и чем платим —
в ADR студии по ссылке. Проект может сделать правило строже; ослабить — только ADR-отступлением
с разрешения владельца ([`../README.md`](../README.md#старшинство-правил)).

В `AGENTS.md` и документах проектов эти правила не пересказываются — туда пишется только то,
как правило выполнено в проекте (какой файл, какой тест), и правила самого проекта.

## Код

- **Стек — Expo / React Native / TypeScript**, рисование — Skia или SVG; версия Expo SDK —
  по возможности одна во всех играх (на 27.09.2026 — SDK 57). Документацию Expo и SDK читать
  по версии, не по памяти (`AGENTS.md` устава) — [ADR 0003](../adr/0003-expo-stack-ci.md).
- **Папки `ios/` и `android/` генерируются** (Continuous Native Generation). Руками не
  создаются и не правятся; нативное поведение — в `app.json` и плагинах конфигурации —
  [ADR 0003](../adr/0003-expo-stack-ci.md).
- **Сборка APK — в CI без EAS**, только после слияния в `main` и вручную —
  [ADR 0003](../adr/0003-expo-stack-ci.md), [`04-process.md`](04-process.md#ветки-и-ci).
- **Движок — чистый TypeScript**: без React, без `Date.now()`, без `Math.random()`. Время,
  случайность и права игрока приходят аргументами; одинаковый вход — одинаковый результат —
  [ADR 0004](../adr/0004-pure-engine-snapshots.md).
- **Сохранение — снимок с версией схемы и миграциями** (или список ходов, переигрываемый
  движком). Изменился формат — шаг миграции и новый образец в тестах; забытая миграция
  стирает игру человека — [ADR 0004](../adr/0004-pure-engine-snapshots.md).
- **Идентификаторы контента вечные**: не удаляются, не переименовываются, выпущенное
  не меняется — исправление выходит новой версией записи — [ADR 0004](../adr/0004-pure-engine-snapshots.md).
- **Все строки для игрока — в `src/i18n/`** (тексты контента — в `content/`), читаются
  при отрисовке; тест проекта ловит строки для игрока вне этих папок.
- **Никогда `Alert` из React Native** — свой диалог (из «Вотчины»): системный диалог
  не работает в веб-сборке, на которой идут проверки.
- **Общий код — копированием с пометкой источника** в первой строке файла —
  [ADR 0002](../adr/0002-copy-not-share.md).

## Сеть, сервер, профиль

- **Всё, что можно без сервера, работает без сети**: игра с ботом, вдвоём на одном телефоне,
  одиночная кампания — [ADR 0005](../adr/0005-offline-first-own-server.md).
- **Сервер — на своей машине студии в России** (сейчас — машина сайта gornitsa.games), Bun
  или Node и SQLite; данные игроков не хранятся в иностранных облаках. Исключение на переход:
  «Вотчина» пересылает запросы версий старше 2.10.2 через Cloudflare и держит там старую
  копию базы, пока такие версии не уйдут (её ADR 0019) —
  [ADR 0005](../adr/0005-offline-first-own-server.md).
- **С версии 1.0 сервер понимает предыдущую выпущенную версию приложения**; несовместимой
  отвечает понятным «обновите игру» — [ADR 0005](../adr/0005-offline-first-own-server.md).
- **Профиль — ключ устройства и ник.** Ни почты, ни телефона, ни пароля, ни входа через
  соцсети; перенос на другой телефон — одноразовым кодом — [ADR 0007](../adr/0007-device-key-no-accounts.md).
- **Идентификатор приложения `games.gornitsa.<игра>` и ключ подписи — навсегда**, с первой
  сборки, которую кто-то поставил на телефон — [ADR 0006](../adr/0006-permanent-app-id-and-key.md).

## Данные игроков

- **Никаких SDK аналитики и трекеров.** Своя минимальная статистика: счётчики без
  идентификаторов человека, раз в сутки, на свой сервер — [ADR 0008](../adr/0008-minimal-data.md).
  Статистика и отчёты о сбоях внутри SDK оплаты RuStore Pay — часть оплаты
  ([ADR 0009](../adr/0009-money.md)), а не наша аналитика — [`07-privacy.md`](07-privacy.md).
- **Сервер хранит только то, без чего не работает онлайн**, со сроками хранения; любые данные
  удаляются по просьбе игрока — [ADR 0008](../adr/0008-minimal-data.md), [`07-privacy.md`](07-privacy.md).
- **Разрешения Android — по белому списку проекта**; новое разрешение — только вместе
  с правкой политики конфиденциальности.
- **Политика конфиденциальности одна** — на сайте, с разделом на каждую игру — [`07-privacy.md`](07-privacy.md).
- **Данные игроков из России не уходят за границу; моделям ИИ — только обезличенный текст.**
  Сборка для зарубежных игроков — отдельная, со своим сервером и без России в странах
  распространения — [ADR 0014](../adr/0014-two-regions.md).

## Деньги

- **Деньги не покупают преимущество над человеком**, а в одиночной игре — и силу: ни скорости,
  ни ресурсов, ни лучших шансов — [ADR 0009](../adr/0009-money.md).
- **Ни лутбоксов, ни сундуков, ни ставок, ни игровой валюты за деньги, ни призов** —
  [ADR 0009](../adr/0009-money.md).
- **Покупки — RuStore Pay на телефоне; сервер о покупках не знает** —
  [ADR 0009](../adr/0009-money.md).
- **Реклама — только между партиями**, не в первых партиях, отключается одной покупкой
  навсегда; реклама за награду — только по желанию; баннеров нет. Рекламный SDK — только
  в игре, чья модель денег — реклама (сейчас «Длинные нарды») — [ADR 0009](../adr/0009-money.md).
- **Подписка — без пробного периода с автосписанием**; начатое при подписке остаётся
  доступным после её окончания — [ADR 0009](../adr/0009-money.md).
- **Добровольная поддержка — снаружи игры**, и внутри за неё ничего не даётся —
  [ADR 0009](../adr/0009-money.md).

## Без давления

- **Ни энергии, ни таймеров ожидания, ни серий входов, ни наград за каждый день** —
  [ADR 0010](../adr/0010-no-pressure.md).
- **Пропущенный день ничего не отнимает**: всё, что копится само, ждёт игрока —
  [ADR 0010](../adr/0010-no-pressure.md).
- **Ни всплывающих предложений, ни счётчиков «осталось 2 часа», ни «последнего шанса −50 %».**
  Магазин игры предлагает себя только в местах, перечисленных в документах игры —
  [ADR 0010](../adr/0010-no-pressure.md).
- **Уведомления — только локальные и по согласию**, только о том, чего игрок сам ждёт
  («ваш ход», «дружина вернулась»), и не чаще раза в день, если это напоминание; никаких
  «мы соскучились»; пуш-серверов нет — [ADR 0010](../adr/0010-no-pressure.md).

## Честность

- **Бот никогда не выдаётся за человека** — [ADR 0011](../adr/0011-honest-play.md).
- **Случайность, которая решает исход против человека, проверяема** (сервер заранее показывает
  отпечаток зерна и раскрывает его после партии); бот не знает будущих бросков и порядка
  колоды — [ADR 0011](../adr/0011-honest-play.md).
- **Шансы в добыче показаны игроку**, невезение ограничено — [ADR 0011](../adr/0011-honest-play.md).
- **Свободного текстового чата нет** — готовые фразы и смайлы: не нужны ни модерация,
  ни возрастные ограничения — [ADR 0011](../adr/0011-honest-play.md).

## Контент

- **Тексты, правила, сказки, медицина, картинки, музыка — только из названных источников**
  с правовым основанием; никогда по памяти — [ADR 0012](../adr/0012-content-sources.md),
  [`06-content.md`](06-content.md).
- **Никаких изображений из генераторов** — ни в игре, ни в магазине, ни на сайте —
  [ADR 0012](../adr/0012-content-sources.md).
- **Ничего из чужих игр, мультфильмов и франшиз**: ни данных, ни облика, ни имён —
  [ADR 0012](../adr/0012-content-sources.md).
- **Отметку `review: checked` ставит только человек**; агент пишет `review: draft` —
  [ADR 0012](../adr/0012-content-sources.md).
